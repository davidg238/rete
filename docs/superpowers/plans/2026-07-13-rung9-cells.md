# Rung 9 — Cells: a name that has a value — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the space a second kind of name — a **cell**, which *holds* the latest
letter instead of being emptied by reading — so that a job which crashes and is restarted
by the supervisor can **read its setpoint back with no network, no bridge, and nobody to
ask.**

**Architecture:** A value slot on `struct SpaceChannel`, three append-only prims, and two
`Channel` methods. `space_put` writes the slot **and enqueues an event on the existing
ring**, so `whenever:` reactions fire through the unchanged reactor — no second delivery
mechanism, no change to `Space>>drain`. The difference between a cell and a stream, from
the reactor's side, is only that the cell **also kept a copy**.

**Tech Stack:** C99 engine (`tuvm/src/space.c`, `dispatch.c`, `platform.c`), Newspeak
dialect (`nsl-tuvm/lib/kernel.ns`), tuvm Model-A solidifier + Model-B `.oimg`, the
`nsl-tests` conformance suite.

**Spec:** `docs/superpowers/specs/2026-07-13-rung9-cells-design.md`
**Decision:** tuvm#32 — **option A**, ratified by David 2026-07-13. Decks:
`tuvm/review/cells-and-streams-v3.html`; code: `tuvm/review/cells-sketch.ns`.

## Task 1 — the value slot in `space.c`

- [ ] `struct SpaceChannel` gains `oop value; uint8_t kind; uint8_t has_value;`
      (`kind`: 0 unset · 1 stream · 2 cell). `space_intern` zeroes them.
- [ ] `space_put(path, len, value)` — intern; **kind check** (a stream → raise); set
      `kind = CELL`, `value`, `has_value = 1`; **then `space_post_id(chan, value)`** so
      `whenever:` reactions fire through the existing ring/reactor unchanged.
- [ ] `space_has_value(path, len)` → int. `find_channel` only — **must not intern**
      (asking about a name must not create it; same rule `space_take` already obeys).
- [ ] `space_peek(path, len)` → oop.
- [ ] `space_post` / `space_take` gain the mirror kind check (a cell → raise).
- [ ] **`space_gc_trace` marks `channels[i].value` for every channel with `has_value`.**
      *The one silently-catastrophic edit in this rung.*
- [ ] Kind mismatch raises an ordinary nsl condition (`vm_raise`, the `error:tag:` idiom
      at `dispatch.c:828–872`) — **not `abort()`**: it is reachable from safe nsl code and
      must be catchable with `on:do:` and attributable by the supervisor.

**Gate:** `tuvm/tools/run_c_tests.sh` green; `tests/test_portability_32.sh` green.
