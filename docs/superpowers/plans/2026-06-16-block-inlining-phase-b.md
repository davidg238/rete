# Block Inlining — Phase B (if-family inlining) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compile `ifTrue:` / `ifFalse:` / `ifTrue:ifFalse:` / `ifFalse:ifTrue:` with literal block arguments inline into the enclosing frame (conditional jumps + direct registers, no closures), turning the reflective `home`/`regAt:` flood into register access and adding the missing `ifFalse:ifTrue:`.

**Architecture:** In `compile_expr`'s `et == "send"` branch, detect an if-family selector whose arguments are all literal zero-parameter blocks and lower it with the Phase A jump helpers (`new_label`/`bind_label`/`emit_jump`/`finalize_jumps`) and a new `compile_inlined_block` helper that compiles a block's body directly into the current `MethodCompiler` under a pushed child `Scope` (same frame → enclosing vars resolve as plain registers, `^` becomes a normal return for free). Anything not matching (e.g. `cond ifTrue: aBlockVar`) falls through to the existing closure+send path unchanged.

**Tech Stack:** Python compiler (`ns-oevm/tools/ns_compile_oevm.py`); conformance harness (`ns-oevm/tools/run_tests_oevm.py`); C VM already supports `OP_JMP`/`OP_JMP_IF_FALSE` (Phase A); perf via `oevm/bench.sh`.

**Design refs:** spec `ns-oevm/docs/design/2026-06-16-block-inlining-design.md` (§"Inlining transformation"); `oevm/docs/topics.md#block-inlining`, `#scope-vs-frame`, `#reflective-frame-access`.

- **This is NOT a byte-identical no-op.** Inlining deliberately changes generated bytecode for every test that uses an if-family selector with literal blocks. The Phase A `snapshot_images.py` + `diff -r` gate does **not** apply to Phase B. The gate is behavioral conformance plus the structural fib check below.
- **Not-taken value = the `false` symbol.** When an arm is absent (`ifTrue:` with a false condition, `ifFalse:` with a true condition), the result register must be loaded with the `false` symbol via `self.add_constant("false")` + `OP_LD_CONST` — identical to the `bool` literal path and to what the `ifTrue:`/`ifFalse:` primitives return.
- **Inline only literal zero-param blocks.** Lower inline only when **all** arguments satisfy `a["type"] == "block" and not a.get("params")`. Otherwise fall through to the existing closure+send path (do not break `cond ifTrue: someBlockVar`).
- **Do not special-case `^`.** Inlined block bodies are compiled with the existing `compile_statement`, so a `^` inside them emits `OP_RET` in a method frame and `OP_NLR` in a non-inlined block frame automatically (the frame is decided by `"_block" in self.name`). Do not add return handling.
- **Reuse Phase A jump infrastructure as-is.** `new_label`/`bind_label`/`emit_jump`/`finalize_jumps` already exist and are flushed at every frame body-completion site (method, block, initializer). Do not re-implement jump encoding; do not add extra `finalize_jumps()` calls.

- [ ] **Step 2: Add the `compile_inlined_block` helper**

Add this method to the `MethodCompiler` class, immediately after the `finalize_jumps` method:

```python
    def compile_inlined_block(self, block, target_reg):
        # Compile a literal block's body directly into THIS frame (no closure).
        # Push a child Scope sharing this frame (so its vars and the enclosing
        # frame's vars resolve as plain registers, frame_depth 0), declare the
        # block's temps as fresh registers, compile the body so its value lands
        # in target_reg, then pop the scope and reclaim the temp registers.
        # `^` inside the body is compiled by compile_statement against THIS
        # frame, so it becomes OP_RET (method) or OP_NLR (non-inlined block)
        # automatically. See oevm/docs/topics.md#block-inlining.
        saved_free = self.next_free_reg
        saved_scope = self.current_scope
        self.current_scope = Scope(self, saved_scope)
        for t in block.get("temps", []):
            self.current_scope.declare(t, self.alloc_reg())
        body = block["body"]
        if not body:
            self.emit_ABx(OP_LD_CONST, target_reg, self.add_constant(None))
        else:
            for stmt in body[:-1]:
                self.compile_statement(stmt)
            last = body[-1]
            if last["type"] == "return":
                self.compile_statement(last)        # emits OP_RET / OP_NLR
            else:
                self.compile_expr(last, target_reg)  # value falls through
        self.current_scope = saved_scope
        self.next_free_reg = saved_free
```

- [ ] **Step 2b: Add the `compile_if_inline` helper**

Add this method to `MethodCompiler`, immediately after `compile_inlined_block`:

```python
    def compile_if_inline(self, selector, receiver, args, target_reg):
        # Lower an if-family send to jumps. `target_reg` holds the result.
        # An absent arm yields the `false` symbol (matches the primitives).
        if selector == "ifTrue:":
            true_block, false_block = args[0], None
        elif selector == "ifFalse:":
            true_block, false_block = None, args[0]
        elif selector == "ifTrue:ifFalse:":
            true_block, false_block = args[0], args[1]
        else:  # "ifFalse:ifTrue:"
            true_block, false_block = args[1], args[0]

        cond_reg = self.alloc_reg()
        self.compile_expr(receiver, cond_reg)
        l_false = self.new_label()
        l_end = self.new_label()
        self.emit_jump(OP_JMP_IF_FALSE, cond_reg, l_false)
        # condition truthy:
        if true_block is not None:
            self.compile_inlined_block(true_block, target_reg)
        else:
            self.emit_ABx(OP_LD_CONST, target_reg, self.add_constant("false"))
        self.emit_jump(OP_JMP, 0, l_end)
        # condition falsy:
        self.bind_label(l_false)
        if false_block is not None:
            self.compile_inlined_block(false_block, target_reg)
        else:
            self.emit_ABx(OP_LD_CONST, target_reg, self.add_constant("false"))
        self.bind_label(l_end)
        self.free_reg()  # cond_reg
```
