The P1 bugs, grouped

  • Space-sync durability trio — ALL CLOSED 2026-08-26. #117, #119, #262: porta never re-serves a stream row the node has acked as applied, so goal/do/* cannot re-run across reboots; cells replay as latest-value. #114 closed in the evening session: sys/panic is re-offered from the RebootNote until porta's ACK covers it — and the move exposed that nothing had ever subscribed the path (must-deliver had never delivered once). The deliberate deploy happened: the new binary migrated the live store and re-armed the manifest; nodes recovered within their cadence.
  • Death by refusing gateway — #199 and #232: CLOSED 2026-08-26 (evening board session). The porta-refuse scenario (tenth target scenario, supported --test-refuse-all injector) held a C6 under continuous refusal for 300 s — misses 0 ref 150, no fault — nearly double the 157 s death record. The fix is verified on hardware, not inferred. #114 closed the same session: sys/panic is re-offered until porta's ACK covers it — and moving the publication found that nothing had ever subscribed the path, so must-deliver had never once delivered. The bridge owns both halves now, and the seam gate's new leg 9 watches a row actually arrive.
  • Actuator safety — #201/#202: DEFERRED (David, 2026-08-26). The bell is still on the piezo striker, so a stuck-on pin is noise, not a held load. Re-arms the moment an inductive striker returns.
  • VM semantic traps — #75 and #81. Decoded symbols never = image literals (identity equality, and printString masks it); and timer_zephyr.c k_oops()es on a load condition justified by a claim that is no longer true.
  • #247 — CLOSED 2026-08-26. Diagnostics as a product feature: compiler errors carry file:line:col + the source line; the DNU line names builtin kinds, app-class receivers (the .oimg v10 classnames section), and a did-you-mean.
