Where we are

95 open issues, but the genuine bug load is much smaller than the number suggests; a lot of it is deferred hardware exploration (MagTag / e-paper / upstream Zephyr) and P3/P4 hygiene.

The headline: liveness is won, durability is not. Last week's board campaign closed out the whole wedge/watchdog family — #215's rows, #231's liveness-heartbeat (green on a board 2026-08-22), and #240.2's cad-rearm landed 2026-08-25 as the ninth target scenario. What's left at P1 is a different genus: data loss and replay safety, not hangs.

The P1 bugs, grouped

  • Space-sync durability trio — #114, #117, #119. A stream entry written while the bridge is down is lost (unacceptable for sys/panic); cursor and bootId live in RAM so every reboot re-pulls everything; and a cold boot at cursor 0 can re-execute historical goal/do/* actions. #262 is the live instance of that last one — every dbg/req profile row re-runs its window each boot. These three are one coherent rung of work, and NVS is already mounted, so persistence costs a settings key, not a subsystem.
  • Death by refusing gateway — #199 (+#232, its target scenario). A node whose frames the gateway rejects exhausts its arena and halts in ~157 s while misses 0 reports it healthy. #232 is the queued board-time item precisely because the host cannot answer the death question.
  • Actuator safety — #201/#202: DEFERRED (David, 2026-08-26). The bell is still on the piezo striker, so a stuck-on pin is noise, not a held load. Re-arms the moment an inductive striker returns.
  • VM semantic traps — #75 and #81. Decoded symbols never = image literals (identity equality, and printString masks it); and timer_zephyr.c k_oops()es on a load condition justified by a claim that is no longer true.
  • #247 — CLOSED 2026-08-26. Diagnostics as a product feature: compiler errors carry file:line:col + the source line; the DNU line names builtin kinds, app-class receivers (the .oimg v10 classnames section), and a did-you-mean. Remainder split to #265 (other frozen runtime errors, and runtime source lines via the G4 line-table).

Notable non-P1 bugs with teeth

  • #224 — reported uptime wraps at ~12.4 days; will eventually confuse a dashboard.
  • #263 — new: c6spare's settings-init error at boot may mean bootid persistence is limping. Worth a look while it's the board on the desk.
  • #264 — a never-matching observe regex reads as node death; filed after it bit us.
  • #161/#163 — the codec cost pair: a check-in spends 62% in pushFrame re-encoding the same values.

Priority opinion

The space-sync durability trio is the highest-value coherent bundle — three P1s, one mechanism (NVS-backed cursor/bootId + replay guard), and it de-fangs #262 as a side effect. #232 is the right next board-time item.
