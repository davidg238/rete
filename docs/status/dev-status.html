Where we are

130 open issues, but the genuine bug load is much smaller than the number suggests; a lot of it is deferred hardware exploration (MagTag / e-paper / upstream Zephyr) and P3/P4 hygiene.

The headline: liveness is won, and replay safety landed today. Last week's board campaign closed the wedge/watchdog family (#215, #231, #240.2), and the second session of 2026-08-26 closed the space-sync durability trio's replay half: #117, #119 and #262 are CLOSED (porta-side stream guard: cursor_hw bounded by served_hw, plus a pull door that refuses an impossible cursor; the node's cursor stays RAM by design — the guard is what makes cursor-0 safe). #114 (must-deliver) is DECIDED, not closed — its implementation rides #232. Design record: porta/docs/design/2026-08-26-space-sync-durability-trio-design.md.

The P1 bugs, grouped

  • Space-sync durability trio — mostly CLOSED 2026-08-26. #117 and #119 closed (with #262, the live re-execution instance): porta never re-serves a stream row the node has acked as applied, so goal/do/* cannot re-run across reboots, and cells replay as latest-value (idempotent). What remains is #114 (must-deliver = re-offered-until-acked from a durable source; sys/panic's source is the RebootNote) — decided, riding #232. Deploy note: the new porta binary migrates the live store on first open; a restart costs nodes an outage, so ship it at a deliberate moment.
  • Death by refusing gateway — #199 (+#232, its target scenario). A node whose frames the gateway rejects exhausts its arena and halts in ~157 s while misses 0 reports it healthy. #232 is the queued board-time item precisely because the host cannot answer the death question.
  • Actuator safety — #201/#202: DEFERRED (David, 2026-08-26). The bell is still on the piezo striker, so a stuck-on pin is noise, not a held load. Re-arms the moment an inductive striker returns.
  • VM semantic traps — #75 and #81. Decoded symbols never = image literals (identity equality, and printString masks it); and timer_zephyr.c k_oops()es on a load condition justified by a claim that is no longer true.
  • #247 — CLOSED 2026-08-26. Diagnostics as a product feature: compiler errors carry file:line:col + the source line; the DNU line names builtin kinds, app-class receivers (the .oimg v10 classnames section), and a did-you-mean. Remainder split to #265 (other frozen runtime errors, and runtime source lines via the G4 line-table).
