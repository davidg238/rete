# R7 Fibers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add language-level cooperative concurrency (a gated `Concurrency` capability with a scheduler + `yield` + `spawn` + lifecycle) on top of oevm's existing fiber VM primitives, desktop-first, both image paths.

**Architecture:** The VM already provides the mechanism (`fiberCreate:`, `fiberSwitch:value:`, GC, stack finalization). This plan adds one tiny VM accessor (`currentFiber`), a pure-`.ns` `Concurrency`/`Fiber` facade in `lib/kernel.ns` that implements an asymmetric cooperative scheduler over those prims, and the capability-grant wiring on both paths (Path A compiler-emitted C; Path B `.oimg` `format_version 7` + loader mirror). Policy lives in `.ns`; mechanism in C — matching the `Serial`/`Net` capabilities.

**Tech Stack:** C99 (oevm VM), Newspeak `.ns` dialect (ns-oevm), Python build/serialize tooling (`ns_compile_oevm.py`, `oimg_serialize.py`), the `run_tests_oevm.py` conformance runner.

**Spec:** `ns-oevm/docs/design/2026-06-29-r7-fibers-design.md`

## Global Constraints

- **Both image paths must pass:** Path A (`solidified_image.c`) and Path B (`.oimg`). The runner runs both per test; the suite is currently **72 passed / 0 failed / 6 skipped**. It must stay green on both.
- **32- and 64-bit:** `oop_size` is 8 (64-bit) or 4 (32-bit, `-m32`). The `portability-32` gate must stay green.
- **`.ns` dialect rules:** collaborating classes **nest** (top-level siblings are not bare-name reachable); **temps hoist to the top** of a method; `basicAt:` is **1-based**; reach VM primitives by **sending to the kernel instance**; no `asInteger`.
- **Capability confinement:** a module not handed a capability via its header param cannot name it — a bare reference in an undeclared body is a **runtime DNU/abort**.
- **C unit test link set** (NOT `kernel_boot.c` — its static `Vtable_*` clash with `solidified_image.c`): `src/vm.c src/gc.c src/dispatch.c src/platform.c src/serial.c src/udp.c src/mirror.c src/backend/posix/platform_posix.c src/backend/posix/serial_posix.c src/backend/posix/udp_posix.c src/oimg_loader.c src/solidified_image.c` + the test file + `-lm`.
- **Repos:** VM changes in `~/workspace/oevm`; facade/grant/tooling in `~/workspace/ns-oevm`; tests in `~/workspace/ns-tests`. Commit per-repo. Do not push (owner pushes).
- **Run the suite from** `~/workspace/ns-oevm`: `python3 tools/run_tests_oevm.py`.

```newspeak
  class Concurrency = ( | kernel readyQueue current schedulerFiber yieldMark doneMark | ) (
    (* Pure-.ns cooperative scheduler over the universal fiber prims. `kernel`
       is the Kernel instance used to reach fiberCreate:/fiberSwitch:value:/
       currentFiber. yieldMark/doneMark are identity sentinels passed through
       fiberSwitch so the scheduler can tell a yield from a completion. *)
    setKernel: aKernel = (
      kernel:: aKernel.
      readyQueue:: OrderedCollection new.
      yieldMark:: Object new.
      doneMark:: Object new.
      ^ self )
    public spawn: aBlock = ( | entry f |
      entry:: [ aBlock value. self complete ].
      f:: Fiber onVm: (kernel fiberCreate: entry).
      readyQueue addLast: f.
      ^ f )
    public yield = ( ^ kernel fiberSwitch: schedulerFiber value: yieldMark )
    complete = ( ^ kernel fiberSwitch: schedulerFiber value: doneMark )
    public run = ( | f signal |
      schedulerFiber:: kernel currentFiber.
      [ readyQueue isEmpty ] whileFalse: [
        f:: readyQueue removeFirst.
        current:: f.
        signal:: kernel fiberSwitch: f vm value: nil.
        (signal == doneMark)
          ifTrue: [ f markDead ]
          ifFalse: [ readyQueue addLast: f ] ].
      ^ self )
  ) : (
    public onKernel: aKernel = ( ^ self new setKernel: aKernel )
  )

  class Fiber = ( | vm done | ) (
    setVm: aVm = ( vm:: aVm. done:: false. ^ self )
    public vm = ( ^ vm )
    public isDone = ( ^ done )
    markDead = ( done:: true. ^ self )
  ) : (
    public onVm: aVm = ( ^ self new setVm: aVm )
  )
```

## Notes for the implementer

- **Symbol resolution in grants:** `compiler.solidify.symbols["concurrency"]` (Path A) and the Path B ref must point at the *same* `concurrency` selector the Kernel method defines. Because the method exists in `kernel.ns`, the symbol is registered during solidification; if a KeyError occurs, confirm the method compiled (it must be a real Kernel method, even though non-public).
- **`Object new` sentinels:** `yieldMark`/`doneMark` rely on identity (`==`). Two separate `Object new` instances are distinct; `signal == doneMark` is an identity test (`PRIM_eqeq`). Do **not** use string/symbol literals for the marks (avoids any literal-pooling identity surprises).
- **First switch into a fresh fiber:** `kernel fiberSwitch: f vm value: nil` enters the fiber at its `entry` block; the `nil` value is irrelevant on first entry. On a later resume, the value is what `yield` returns (unused). This matches `primitive_fiber_switch` semantics.
- **net + concurrency in one entry is unsupported** (the loader binds a single "second cap"; the existing ns-oevm#2 limitation). Fiber MVP tests use `concurrency` alone. The fiber-aware I/O tier will need to lift this.
- **If `45_fibers.ns` interleave order is unexpected:** trace whether `run`'s `schedulerFiber:: kernel currentFiber` is captured *before* the first switch (it must be — `run` executes in the caller/scheduler fiber). The wrapper's `self complete` must be the *last* thing each fiber does.
