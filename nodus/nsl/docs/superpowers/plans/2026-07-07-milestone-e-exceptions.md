# Milestone E — full `on:do:` / `ensure:` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land full `on:do:` (predicate-filtered catch), `ensure:` (always-run cleanup), and tagged raise (`error:tag:`, `raise`) on the host reactor, layered on Milestone D's crash boundary — closing phase-2 rung 1 (spec `2026-07-07-milestone-e-exceptions-design.md`).

**Architecture:** Milestone D already unwinds to a marked frame via `vm_protected_fire` (setjmp), chaining protection frames through a saved `g_protect_top`. E adds two more variants of that same C helper — `vm_on_do` (setjmp; run protected block; on a caught fault evaluate a predicate block, run the handler block if it matches, else re-raise to the next frame) and `vm_ensure` (setjmp; run protected block; always run the cleanup block; re-raise if the exit was a fault) — dispatched as ordinary primitive sends on a block receiver. The in-flight error value becomes the same crash `Record` (`#tag`/`#text`) the supervisor already reads: `error:tag:` builds it in nsl and raises it; an uncaught error reaches the reactor's `vm_protected_fire` exactly as in D and posts to `sys/crash`. No compiler change (prim-sends, not inlining); no new concurrency; host-only.

**Tech Stack:** C11 (tuvm VM, `~/workspace/tuvm/src`: `vm.c`, `dispatch.c`, `platform.c`, `gc.c`, `oevm.h`, `prim_ids.h`), the nsl dialect (`~/workspace/nsl-tuvm/lib/kernel.ns`), the Python test runner (`nsl-tuvm/tools/run_tests_oevm.py`), black-box `.ns` conformance tests (`~/workspace/nsl-tests`).

## Global Constraints

- **Build additively on D's boundary; do NOT rework it.** `vm_raise` / `vm_protected_fire` / `g_protect_top` / `g_raised_condition` (`vm.c:54-106`) stay as-is; E adds `vm_on_do` and `vm_ensure` beside them, each saving/restoring `g_protect_top` the same way `vm_protected_fire` does (`vm.c:88,104`) so re-raise cascades frame-by-frame. The reactor's `vm_protected_fire` remains the outermost frame (uncaught → `sys/crash`, unchanged — spec §7).
- **Terminate-only; handler runs after unwind; a crash never crosses a dispatch boundary** (exceptions.md C2/C3/C5). No `resume:`, no `retry` (spec §10). The walk stops at the current firing's reactor frame at the latest.
- **The in-flight error value is the crash `Record`** (`#tag`, `#text`); `#channel` is attached only when it reaches the reactor boundary (D's `postCrash:channel:`, immutable-construct-new — spec §3). Handlers/predicates read `e tag` / `e text`.
- **Prim numbering is append-only.** Never insert mid-list or shift an existing id. The `dispatch.c` enum and `PRIM_NAMES[]` stay index-parallel (`index i → id i+1`); `prim_ids.h` mirrors platform-prim numbers as hand-written absolutes. D's last platform prim is `PRIM_pf_advanceMillis = 89`. **New platform prims start at 90 — verify by counting `PRIM_NAMES` entries, never by mirrored-id arithmetic** (the 73→79 trap). Renumber `prim_ids.h` with every insertion.
- **`^` is forbidden in handler/predicate/cleanup blocks** (no-NLR, `07_no_nlr`) — they are real closures. Authors capture the `on:do:` result and `^` it from the method body. A test asserts the compile error (Task 5).
- **Precise non-moving GC, exhaustion-triggered:** any C local holding an oop across an allocation must be rooted (`gc_temp_roots_count` SAVE/RESTORE, `gc.c` `context_alloc` precedent — spec §8). `g_raised_condition`, the predicate/handler/cleanup closures, and any materialized Record are live across `run_interpreter` re-entry and MUST be rooted. This is the recurring project bug; hunt it in every C diff.
- **Two generated byproducts to restore before any commit:** `tuvm/src/solidified_image.c` AND `tuvm/src/solidified_image.stmap` (Path A compiles churn both). Gitignored artifacts (`oevm_runner`, `__pycache__`) evade `git status` — verify with explicit `ls`/`find`.

Implementers run **single-file both-path checks only** (drive `run_test_file` / `run_test_file_oimg`) + commit; **the controller owns every full-suite run** (D concurrency lesson — two suite runs race on `solidified_image.c` and produce spurious `A:FAIL B:PASS`). Both paths (A = solidified, B = `.oimg`) must be byte-identical green.

## Task 1: Tagged error value — `error:tag:`, `raise`, and the Record-valued raise

Make the in-flight error a crash `Record`. `error:tag:` (new kernel method, reachable — NOT a prim name, so `send_resolve`'s prim interception at `dispatch.c:788` does not shadow it) builds `Record tag: aTag with: #text -> aText` and raises it via a new `raise` prim. `error:` is redefined to route through `error:tag:` with the default tag `#error`.

**The `error:` subtlety (fixed decision for this plan):** `error:` is pre-existing prim id 9 (`"error:"` in `PRIM_NAMES`, `PRIM_error` case at `dispatch.c:1015`), intercepted for every receiver before method lookup — so it cannot be reimplemented as a kernel method without removing it from the table (which would shift all later ids — forbidden). Keep `error:` as prim id 9, and change `PRIM_error`'s body from `vm_raise(args[0])` to **re-dispatch** `self error: args[0] tag: #error` via a `send_resolve` re-entry (self is the prim's receiver). Heap receivers reach the kernel `Object>>error:tag:` method (memory: heap instances reach kernel-Object methods); the rare builtin receiver that lacks it falls back to raising `args[0]` directly (preserve today's behavior). Escalate if this re-entry proves unsound.
